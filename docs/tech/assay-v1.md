## 1. 范围与原则

**本文定**：GDD §8.3 八项测试在整数参考实现上的算法、阈值、取整和记录；8 个行为大类的机器判据；柏拉图型的操作性定义；自我修复的扰动协议和鉴定用的确定性伪随机数生成器（规范 §9.2 留给本文）；证书内容；算力、排队、失败与重试；描述助手能从证书抄什么；黄金样本集；文献导入"行为没有明显改变"的口径（法规第 42 条留给本文）。

**第一阶段的范围**（PRD F16；七项必测，自我修复可以先"未测"，PRD 第 13 节第 2 条的新提议）：

**原则**：

1. **只信参考实现。** 证书只来自服务器上 lenia-q16 参考实现的运行（GDD §14.8）。浮点预览值、仪器读数（F10）和客户端上报的任何测量都不进证书【待 D-029】。测量值和类别由程序算出，任何人都不能手改（红线 1）；认为判错了，按套件 bug 处理（§6.5，D-027(4)）或等套件升级，不改单张证书。
2. **全部用整数和有理数。** 每个测量、每个判据都只用整数运算和精确的有理数比较；要输出小数的，最后一步按 §6.4 取整。证书主体（`engine`、`issued_at`、`sig` 除外）任何人都能逐位复算。这比 D-034 建议的分层更严：分层允许描述性的量用 float64，v1 也用整数算，规范性部分没有浮点后处理。以后（如第二阶段的频谱）要用浮点的量，必须在证书里标"非规范"、写明精度和实现版本，不得参与任何判据【待 D-034】【新提议 AS1】。
3. **按时间单位计。** 运行长度按时间单位，2000 个时间单位＝2000·T 步（D-012 已采纳；数值【待 D-033】）。哈希链间隔按步数，256 步（规范 §8.5【待 D-033】），与本文的采样间隔无关。
4. **套件版本独立**【新提议 AS2】。套件写作 `assay/1.0.0`，与规范版本（`lenia-q16/1.0`）和引擎版本（`ref-1.x`）分开发布。每个套件版本列出支持的规范版本，附阈值表（§5）、TRIG 表（§2.4）和黄金样本（§10）的哈希。补丁号：修实现与本文不符的 bug，判据和阈值不变，修好后结果变了的证书按 §6.5 更正；次版本号：只加测量项或检测器，原有字段的含义和阈值不变；主版本号：改阈值或判据。证书永远按签发时的套件解读。
5. **不调参。** 离散化变体是测试，不用来让任何标本"活下来"，文献种也一样（D-040 第 1 条【待 D-040】；法规第 44 条）。
6. **证书里没有个人数据。** 鉴定只读采集记录的 `spec`、`params`、`n`、`state`，不读探索路径和好奇心数据，与同意级别无关；0 级账户照常送检，D-031 允许未成年人注册时未成年账户也一样（GDD §11.2、D-012）【待 D-031】。账户编号只在私密的队列表里用于公平排队（§7.2），鉴定完成后从队列表删除，不进证书和事件载荷；`assay.requested` 按数据模型 §6.1 用玩家的每事件署名标识，`assay.certified`、`assay.failed` 的行为者写 `{"kind": "system", "id": "assay"}`。

## 2. 输入、尺寸与运行

### 2.1 输入与合法性

工作节点读采集记录的参数记录（规范 §8.2）、`n` 和状态记录 S0（规范 §8.4），按规范 §9.1 自己生成核和查找表，算出 hP、hK、hG（部分符合的实现不能用于鉴定）。下面任何一条不满足就不运行，写 `assay.failed` 和原因码（§6.2），不签证书：规范标识是 `lenia-q16/1.0`（草案不用于登记，规范 §1；P1-W1–W2 的校准和黄金样本可以在草案上跑，产出只作内部测试，不签名、不写事件，v1.0 冻结后全部重跑）；记录合法（规范 §3、§4）；S0 至少有一个活格（§2.4）；尺寸核对通过（§2.2）。

### 2.2 尺寸核对与复查【待 D-025】【新提议 AS3】

- **成体尺寸 D_0**：S0 活格掩膜在 x、y 方向的环面外延（§2.4）取较大者，单位是格。
- **核对**：n 是合法尺寸，并且 n ≥ D_0 + 4R，否则拒绝（`size_rule`）。这是交接规格 CH4 的下限（边距 2R、N ≥ e + 2m）；交接规格的体型 e 取自整段稳定窗口，鉴定只能从 S0 复算，所以只核下限，不要求 n 是最小的；D-025 建议的"取最小合法尺寸"由采集端按 e 落实。交接规格第 3 节的浮点掩膜 > 0.1 按实数比较时恰好对应 ≥ θ_live（binary32 的 0.1f 本身量化为 6554，不能写成 x > 0.1f），所以 D_0 ≤ e，按交接规格采到的标本都能通过核对。尺寸属于模式标本（规范 §4），鉴定不重新裁切：裁切会改变状态哈希，也就改变了采集承诺。
- **required_n(D, R)**：{128, 256, 512} 中满足 N ≥ D + 4R 的最小者；超过 512 记 `too_large`。离散化变体（§3.7）用它选尺寸。
- **复查**：§3.2 列出的情况下，在下一个更大的合法尺寸上再跑一次，排除环面绕回造成的假象（D-025）。

### 2.3 运行计划

一次鉴定由下面几次运行组成，彼此独立，可以并行（§7）。每次都按规范 §8.5 算哈希链，链值 `chain` 和分段列表的哈希 `segments`（数据模型 §3.2）都写进证书，出现分歧时才能定位。

| 运行 | 环面 | 参数 | 长度 | 用于 |
|---|---|---|---|---|
| 基准运行 | n | 原参数 | 2000·T 步 | 存活、局域性、运动、周期、对称、繁殖与辐射；证书的 `trajectory` |
| R↓、R↑、T↓、T↑ | §3.7 | 只改 R 或 T | 2000·T′ 步 | 离散化依赖 |
| 复查 | 下一个更大的合法尺寸 | 原参数 | 2000·T 步 | 只在 §3.2 的条件下跑 |
| 自我修复 × 8 | n | 原参数 | 各 100·T 步 | §3.6 |

### 2.4 公共子程序

全部是整数运算。坐标和取模按规范 §4，rne、isqrt 按规范 §2。

```
θ_live = 6554                 # 活格阈值 ≈ 0.1，与测量报告 §1 的掩膜、交接规格第 3 节相同（暂定）
活格掩膜：A ≥ θ_live 的格子
环面外延：把一组格子投影到 x 轴，找最长的一段首尾相接的空列，长 G；外延 = N − G。
          没有空列时外延 = N，记"绕满"。y 方向同理。
个体簇：活格掩膜按切比雪夫半径 h = ⌈R/3⌉ 膨胀（同交接规格第 3 节），在环面上按 8 邻接求连通分量（并查集）；
        一个分量里的活格是一个簇。簇按其活格的最小行优先下标排序编号。
质心：簇的坐标从最长空段的末端起展开为 0..N−1，c = Σ A·x / Σ A，存为 Q16（rne）。相邻两次采样之间按
      最近像展开成连续轨迹；位移 ≥ N/4 时记 tracking_lost。绕满的簇没有质心，主体是它时也记 tracking_lost。
主体：第 0 步质量最大的簇；之后每次采样取质心离上一次主体最近的簇，并列取质量大的，再取编号小的。
重采样 S(G; c_F, c_G, X)：目标格 p 的源坐标 = c_G + X·(p − c_F)，Q16；双线性插值，权重 Q16，
      结果 rne(Σ w·A, 2^32)，饱和截断。变换 X 是旋转、镜像（cos、sin 查 TRIG 表）或有理数缩放。
TRIG 表：1.25° 的整数倍和 360°/n（n = 2..12）的 cos、sin，Q30。离线用 ≥ 60 位精度算出、rne 取整，
      随套件发布并取哈希【新提议 AS4】。它是测量用的常数，不属于宇宙语义，所以不受 D-022"规范里
      不放离线值"的约束；任何人都能用高精度工具核对。
对齐距离 d(F, G; X) = Σ_{p∈盒} |F(p) − S(G; c_F, c_G, X)(p)| / max(m_F, m_G)，m 是两帧主体的质量，
      盒以 F 的主体质心为中心、边长 2⌈D/2⌉ + 2R（D 是两帧主体外延的较大者）。
      d_T：X 为单位阵（只消除平移）。d_TR：X 取使距离最小的旋转（也消除旋转），先在 10° 网格上找，
      再在其 ±10° 内的 1.25° 网格上找；并列取角度编号小的。
      与阈值比较一律交叉相乘，不做除法。
```

### 2.5 采样与分析窗口【新提议 AS5】

- 每个时间单位（每 T 步）采样一次：总质量 M（u64，单位 1/65535）、活格数、个体簇及各簇的质量、外延和质心、主体。
- 逐步保存主体方框的时段：最后 100 个时间单位（周期，§3.4）；第 1090–1110 个时间单位（自我修复的对照，§3.6）。自转角 Θ（§4.1）在运行中逐帧算，不保存帧。另按交接规格第 12 节，私存基准运行第 257–511 步每步的状态哈希（每件约 8 KiB），供观察记录的挑战校验，不进证书、不随登记公开（证书的链点登记后公开，所以不能拿来做挑战）【待交接规格 CH14】。
- **分析窗口**：存活和局域性看全程；运动、周期、对称、旋转和类别看后一半（第 1000–2000 个时间单位），避开暂态。S0 是浮点帧量化而来（交接规格 CH1、CH5），在整数宇宙里可能还要安顿一阵。与测量报告 §1"取后 1000 个时间单位"一致。

## 3. 各项测试

### 3.1 存活【新提议 AS6】

- **存活**：基准运行每次采样和最后一步（第 2000·T 步）的活格数都 ≥ 1，记 `survived: true`；否则 `false`，并记第一次为 0 的时间单位 `survival.died_at_tu`（本文补充的字段）。
- **质量有界**：全程 max M ≤ 4·M_0（暂定）记 `mass_bounded: true`。有限环面上质量总有上界，这里只表示没有明显增长，是描述性的；扩张由 §3.2 判。
- **产出**：`survival {time_units: 2000, steps, survived}`（数据模型 §3.2）；`mass_mean`（后一半的平均质量，满格为 1，2 位小数）、`mass_ratio_min`、`mass_ratio_max`（相对 M_0，4 位小数）、`size_cells`（D_0）、`size_r`（D_0/R，3 位小数）。
- **判定**：`survived` 为真，鉴定才通过（`verdict: pass`）。扩张体也通过；能不能描述由法规和查重决定，鉴定不另设门槛。只写"在 2000 个时间单位内存活"，不写"永久存活"（D-033）。

### 3.2 局域性与扩张【待 D-025】【新提议 AS3】

- A_0、D_0′：第 0 步主体的活格数和外延。
- **扩张体**：基准运行中 (a) 任何一个簇在 x 或 y 方向绕满；或 (b) 最后一步最大的簇活格数 ≥ 4·A_0，且外延 ≥ 2·D_0′（暂定）。否则为**个体**。
- **复查的条件**：出现 (a) 或 (b)；或者任何一次采样有 ≥ 2 个簇、有两个簇合并；或者某个簇的外延超过 n − 2R（在环面上与自己的间隙小于 2R，暂定）。其余个体只有一个簇，与自己始终隔着至少 2R 的空白，超出核的半径 R，环面绕回影响不到它，所以不复查。按条件复查是对 D-025"256 尺寸标本的局域性和扩张复查用 512"的解释和推广（128 的复查用 256），为了省算力。
- **复查的做法**：把 S0 按主体质心整体平移到 n/2（整数平移，不插值），放进 2n 的全零环面中央，跑 2000 个时间单位，按同样的规则重判。局域性、繁殖和辐射以复查为准，两次都写进证书。n = 512 时没有更大的尺寸，写 `locality_recheck: "unavailable"`（D-025）。
- **产出**：`locality: "individual" | "expander"`；`locality_recheck`：`{n, chain, segments, locality}`、`"unavailable"`，没触发时省略。判为扩张体时，运动、周期、对称和自我修复都不适用，省略（§6.1）。交接规格预检的 `expanding` 提示只是提示，以这里为准。

### 3.3 运动

在分析窗口上取主体质心的连续轨迹 c_0…c_K（K = 1000，每个时间单位一个）。c̄ 是平均位置；r_max 是 c_k 到 c̄ 的最大距离；净位移 Disp 是 c_0 到 c_K 的距离；路程 P 是相邻两点距离之和；直度 S = Disp / P；绕转数 w 是 c_k − c̄ 绕 c̄ 的有向象限跨越数除以 4 向零取整（只数完整的圈；象限按 x ≥ 0、y ≥ 0 的半开区间划分）。距离在 Q16 上用 isqrt 算。

**运动类别**（按顺序，先满足先得；阈值暂定）：

1. r_max ≤ R/4 → 静止 `stationary`
2. w 的绝对值 ≥ 2，且 Disp < 2R → 环行 `orbiting`
3. Disp ≥ 2R，且 S ≥ 9/10 → 直线 `linear`
4. Disp ≥ 2R，且 S ≥ 1/2 → 曲线 `curved`
5. 其余，以及 tracking_lost → 无规则 `irregular`

- **速度单位：R 每时间单位（R/TU）**【新提议 AS7】，即每个时间单位移动的格数除以 R；换成"格/步"再乘 R/T。柏拉图型物种换 R、T 之后这个数应当大致不变，所以选它。GDD §14.5 示例的注释写"格/步，按 R 归一化"，在 T 变化时不可比，本文改为按时间单位。
- **产出**：`motion`；`speed` = Disp/(1000·R)；`velocity` = (c_K − c_0)/(1000·R) 两个分量（x 向右、y 向下，同规范 §4）；`path_speed` = P/(1000·R)，都是 4 位小数；`straightness` 3 位小数；`winding` 整数。方向角只作显示，不进证书。

### 3.4 周期【新提议 AS8】

参考帧 F_ref 是第 1900·T 步的主体方框。对 ℓ = 1…100·T 步算 d_T(ℓ) 和 d_TR(ℓ)（§2.4，F_ref 对第 1900·T + ℓ 步）。

- **形态不变**：全部 ℓ 的 d(ℓ) ≤ ε_per = 1/20 → `periodic`，steps = 1（平凡周期）。
- **周期**：否则只看 d 第一次超过 2·ε_per（"离开"）之后。d ≤ ε 的连续一段叫"回落段"，段内 d 最小的 ℓ（并列取小）是它的极小点。按顺序取 ε = ε_per 的回落段极小点 p，第一个满足 d(2p)、d(3p)（各取 ±1 步内的最小值）都 ≤ ε_per 的 → `periodic`，steps = p。要先离开，是因为相邻几步的帧本来就很像，不然几乎一切都会判成 1 步的周期。3p 不超过 100·T，所以只检测 ≤ 33 个时间单位的周期，更长的记 `none`（暂定）。
- **准周期**：没有周期，但离开之后 ε = ε_quasi = 3/20 的回落段至少 3 个，各极小点从 0 算起的相邻间隔与平均间隔之差都 ≤ 平均间隔的 1/10 → `quasi`，steps = 平均间隔（rne）。
- 否则 `none`，意思是"33 个时间单位内没找到周期"，不是"永不重复"。
- **记两种周期**：`period` 用 d_T（只消除平移，朝向必须相同）；`shape_period` 用 d_TR（也消除旋转）。刚体旋转体的 `shape_period` 是 1 步，`period` 是它转过一个对称角所用的步数。GDD §8.3 写"消除平移和旋转后"，§7 的示例又给旋转体"周期 24 步"，两种都记，免得各读各的。
- **产出**：`period`、`shape_period`，各为 `{kind, steps, time_units}`，time_units = steps/T，3 位小数。

### 3.5 对称【新提议 AS4】

- **取帧**：`period` 是 `periodic` 且 ≥ 8 步时，在最后一个周期内等距取 8 帧；否则在最后 10 个时间单位内等距取 8 帧。
- **旋转**：对 n = 2…12，把帧绕主体质心转 360°/n 与原帧比较，d ≤ ε_sym = 1/20 记 C_n 成立；8 帧都成立才算。报告的 n 是满足"自己和全部约数都成立"的最大 n。
- **镜像**：每帧各自在 0°–180° 的 1.25° 网格上找使 d 最小的对称轴（过主体质心），8 帧都 ≤ ε_sym 记镜像成立。
- **对称群**：有镜像 → `D` 加 n（只有镜像时 `D1`）；没有镜像 → `C` 加 n（都没有时 `C1`）。n = 2…12 全部成立时写 `Cinf` 或 `Dinf`（近似各向同性）。
- **产出**：`symmetry`；镜像轴的网格编号只作显示。

### 3.6 自我修复【新提议 AS9】

P1-W2 末定不下时写 `"untested"`（PRD F16）；扩张体不测，省略。扰动都施加在基准运行第 1000·T 步的状态上（已过暂态），各跑 100 个时间单位：

| 扰动 | 次数 | 做法 |
|---|---|---|
| 噪声 | 2 | 主体按切比雪夫半径 R 膨胀后的区域里，每格加 [−6554, 6554] 的均匀整数，饱和截断；按行优先每格抽一次 |
| 擦除 10% | 2 | 从 16 个方向（22.5° 的整数倍）里抽一个；主体活格按在该方向上相对质心的投影从大到小排（并列按行优先下标），依次置 0，直到擦掉的质量 ≥ 主体质量的 1/10 |
| 擦除 25% | 2 | 同上，1/4 |
| 局部挤压 | 2 | 在主体活格里按行优先编号均匀抽一个作圆心；半径 R 的圆盘内沿径向压缩到 7/10：目标格 p 取源坐标 圆心 + (p − 圆心)·10/7 双线性插值，源点在圆盘外的置 0；圆盘外不动 |

- **恢复**：100 个时间单位内活格数始终 ≥ 1；最后一步的簇数与基准运行第 1100·T 步相同；主体与基准运行第 1100·T ± w 步（w = max(period 步数, T)，`none` 时取 T，不超过 10·T）各帧的最小 d_TR ≤ ε_rec = 3/20。
- **自愈指数** = 恢复次数 / 8，4 位小数，只可能是 1/8 的倍数（GDD §7 示例的 0.71 是虚构的，修订已列入 GDD 附录 D）。分项写成 `{"noise": "2/2", "erase10": "1/2", "erase25": "0/2", "squeeze": "2/2"}`；每次的结果和哈希链写进 `trials`。

**伪随机数生成器**（规范 §9.2 留给本文）【新提议 AS10】【待 D-021】：

```
prng_seed = SHA-256(NTJ({"fmt": "assay-prng-seed/1", "suite": "assay/1",   # 只取主版本号：补丁和次版本不改种子
                         "params": hP, "n": N, "state": S0 的哈希}))      # NTJ 见数据模型 §2.1
块(stream, i) = SHA-256("LQ16APRN" ‖ seed 的 32 个原始字节 ‖ stream (u32) ‖ i (u64))   # 小端，i 从 0 起
```

- 每块拆成 8 个小端 u32，依次取用。均匀取 [0, m)：x ≥ 2^32 − (2^32 mod m) 时丢弃重抽，否则取 x mod m。stream 1–8 依次对应上表 8 次扰动。
- 种子由标本本身算出，不用服务器随机数：任何人都能复算，运营方也没法为某张证书挑种子。代价是种子事先可知；自愈指数是描述性的量，不影响身份和优先权，可以接受。规范附录测试协议第 2 条"固定种子的整数伪随机数"可以用同一个生成器（建议）。

### 3.7 离散化依赖与柏拉图型【待 D-028】【新提议 AS11】

R、T 的合法范围按规范 §3 的提议（R 5–50、T 5–40【待 D-028】）。

| 变体 | 取值 | 能测的条件（不满足记 `not_testable`、`out_of_range` 或 `too_large`） |
|---|---|---|
| R↓ | max(R_min, rne(R, 2)) | 小于 R |
| R↑ | min(2R, R_max) | ≥ ⌈3R/2⌉，并且 required_n(⌈D_0·R′/R⌉, R′) ≤ 512 |
| T↓ | max(T_min, rne(T, 2)) | 小于 T |
| T↑ | min(4T, T_max) | ≥ 2T |

- **改 T**：状态不变，只换查找表，跑 2000·T′ 步。
- **改 R**：成体按 R′/R 缩放。源锚点取 S0 环面外延的中点（整数），放到 N′ = required_n(⌈D_0·R′/R⌉, R′) 的中央；目标格 p 的源坐标 = 源锚点 + (p − N′/2)·R/R′，是精确的有理数，双线性插值，rne，饱和截断。核和查找表按 R′ 重新生成（规范 §5、§6）。
- 每个变体都做完整的存活、局域性判定（不复查），并按 §4 算类别（描述性）。
- **柏拉图型（操作性定义）**：R↑ 和 T↑ 都能测且都存活 → `platonic: true`；能测的 R↑、T↑ 中有一个没存活 → `false`；其余（有一个不能测、能测的都存活）→ 省略 `platonic`，`discretization_runs` 写明哪个没测、为什么。按 D-028 的候选范围，R > 33 或 T > 20 的标本判不了。
- **只看加细**：GDD §5.2 说非柏拉图型"分辨率调得更细反而会解体"，所以只看 R↑、T↑；R↓、T↓ 只用来写能存活的范围。粗到一定程度，连续规则的近似本身就失效，粗化后死亡说明不了依赖离散化。这个标签不等于 Davis（2024）的判据（数据模型 §8.5 数据说明书第 2 条），证书和物种页都这样写。研究简介写的是"在测过的 R、T 下是否存活"，见 §12【待决策日志 E.3：研究简介里"柏拉图型"的说法】；操作性定义合不合适是访谈开放问题 Q-02，访谈结论在本文定稿前处理。
- **能存活的范围**（导出的 `assay_summary.discretization_range`）：测过的值里，从原值起向两侧连续存活的最小值和最大值。只是测过的点，不证明区间内处处存活。
- `dims_tested: ["R", "T"]`；证书写明数值精度这一维第一阶段不测（D-003 的待决部分）。
- **产出**：`discretization_runs`，每项 `{R, T, n, steps, status, survived, locality, classes, chain, segments}`，status 为 `run`、`not_testable`（取得到值，但不满足上表的条件）、`out_of_range`（原值已在范围端点，取不到别的值，如 R = 5 时的 R↓）、`too_large`。这些是在数据模型的 {R, T, survived, chain} 上加的字段（§6.1）。

### 3.8 繁殖与辐射【新提议 AS22】

- **观察窗**：从第 0 步到"拥挤"为止：活格数 > max(N²/8, 2 × 第 0 步的活格数)，或两个不同谱系的簇合并，或任何簇绕满。记 `observed_tu`。触发复查时以复查运行为准（§3.2）。有限环面上发出的移动体迟早会绕回来撞上母体，所以只在拥挤之前计数。
- **分裂**：相邻两次采样之间，一个簇按切比雪夫半径 R 膨胀后与下一次的几个簇重叠，就是分裂；质量最大的继承原簇的谱系，其余是新簇。
- 新簇独立存在满 20 个时间单位（不与其他簇合并）时判定：质量与当时原簇之比在 [1/2, 2] → **子个体**（繁殖事件）；质量 < 1/2，质心离原簇 ≥ 2R，且第 20 个时间单位时比第 10 个时间单位时离得远 → **发射**（辐射事件）；其他 → 碎片，只计数。观察窗结束时还没满 20 个时间单位的新簇不判定，不计数。
- **产出**：`reproduction {events, rate}`、`emission {events, rate, last_event_tu}`、`fragments`、`observed_tu`；rate = 事件数 × 100 / observed_tu（每 100 个时间单位，3 位小数）。

## 4. 行为大类

### 4.1 判据【新提议 AS12】

在分析窗口上判定，可以多选。枚举串是证书和导出用的写法；阈值见 §5。

| 大类 | 枚举 | 判据（全部暂定） |
|---|---|---|
| 固着体 | `sessile` | 个体；运动 `stationary`；所有 ℓ ≤ 100·T 的 d_T(ℓ) ≤ ε_per（形态不变，也不转） |
| 振荡体 | `oscillator` | 个体；`shape_period` 是 `periodic` 或 `quasi` 且 ≥ 2 步；一个 shape_period 内 max d_TR ≥ 3·ε_per（形态真的在变，不只是在转） |
| 移动体 | `mover` | 个体；运动不是 `stationary` |
| 旋转体 | `rotator` | 个体；对称群不是 `Cinf`、`Dinf`；自转角 Θ 与运动方向转角 Φ 之差的绝对值 ≥ 2 × 360°/n（n 取对称群 C_n 或 D_n 里的 n，`C1`、`D1` 时 n = 1）；Θ − Φ 每 10 个时间单位的非零增量中同号的 ≥ 9/10 |
| 复制体 | `replicator` | 繁殖事件 ≥ 2（§3.8） |
| 辐射体 | `emitter` | 辐射事件 ≥ 3；原簇在观察窗结束时仍在；最后一次发射在观察窗的后一半（"持续"） |
| 扩张体 | `expander` | 局域性为扩张（§3.2） |
| 混沌个体 | `chaotic` | 个体；`period` 和 `shape_period` 都是 `none`（33 个时间单位内没找到周期，§3.4） |

- **自转角 Θ**：分析窗口内每 max(1, ⌊T/8⌋) 步取一帧，与窗口的第一帧比较；在上一帧角度 ±min(22.5°, 180°/n − 1.25°) 的范围内找使 d_TR 最小的 1.25° 网格角，得到连续的绝对角度，网格误差不累积。**运动方向转角 Φ**：每 10 个时间单位（暂定）的质心位移按 TRIG 表取点积最大的网格角，同样展开累加；位移 < R/4 的段沿用上一段的方向，`stationary` 时 Φ = 0。用 10 个时间单位的基线，是为了不让慢速漂移的方向噪声打乱 Θ − Φ 的符号。这样，沿圆周游动、身体跟着转向的移动体不算旋转体，GDD §7 里"边转边漂移"的近亲算旋转体加移动体。
- `angular_velocity` = (Θ − Φ)/1000，度每时间单位，3 位小数。

### 4.2 多选与空集

- 一个标本可以属于几个大类，例如会脉动的移动体是 `mover` 加 `oscillator`。判为扩张体的不再判固着体、振荡体、移动体、旋转体、混沌个体。
- 可以一个都不满足，例如 1000 个时间单位里转不到两圈的不对称个体。证书写 `classes: []`，物种页写"未归入行为大类"；不影响通过鉴定，也不影响描述。类别只是机器标签（GDD §8.4 的行为分类），不是系统分类。

### 4.3 新类别的检测器接口（第二阶段）【新提议 AS13】

第一阶段不接入玩家提议的类别（PRD 第 4 节）。先定接口，免得以后改证书格式：检测器是纯函数，输入只有 §2.5 的采样记录、逐步方框和证书的 measures，输出真或假，只用整数，有名字、版本和代码哈希。采纳一个类别＝套件升次版本，阈值进阈值表，原有类别的判据不变。已签发的证书不自动重判，需要时签补充证书（§6.5）。定义者记在行为类别实体的 `defined_by`（数据模型 §3.6，GDD §3.2(4)）。

| 玩家在完成前删除了标本 | 不签 | `assay.failed` | `cancelled` |

- 只有 `pass` 的证书满足法规第 14 条第 1 款。`died` 的证书和状态按数据模型 N11 保留。
- 送检不占描述配额（法规第 18 条按描述计），次数受交接规格第 11 节的送检额度限制。同一账户对同一组输入、同一套件重复送检，直接返回已有证书；不跨账户复用结果，免得透露别人送检过什么（法规第 9 条）。

### 6.3 签名、编号与复核

- **签名**：Ed25519，对去掉 `sig` 的证书的 NTJ 字节签名，算法和写法与每日链头、导出清单相同（数据模型 N6、§8.2），但不是同一把键：证书键只签证书和悬赏判定结果，链头和导出清单用链头键（[系统架构](./architecture.md) §7.1【待 AR9】）。私钥只在密钥托管服务里，只有签名器能调用，工作节点只能经签名器请求签名；密钥编号、轮换、吊销和泄露后的重跑重签见系统架构 §7（PRD F17、R22）【待 AR10】。
- **编号**：`cert:sha256:` 加去掉 `sig` 之后的 NTJ 哈希（数据模型 §2.2 只写了"内容哈希"）。签名不进编号：密钥轮换或泄露后重新签名，编号不变，已登记条目里的引用不用改；同一编号因此可能有几份签名，导出时全部附上，吊销的标明吊销时间（PRD R22）【新提议 AS14】。
- **复核**：任何人用符合规范的引擎和同一版本的套件，对同一组输入复算，除 `engine`、`issued_at`、`sig` 之外逐字节相同。不同时按规范 §9.3 定位，按 D-027 处理【待 D-027】。

### 6.4 取整与写法【待 D-034】【新提议 AS1】

- 每个小数测量先算成精确的有理数，再按 rne（规范 §2）取到 §3 规定的位数（最多 4 位小数），写成十进制串，去掉末尾的 0 和多余的小数点（"0.7500" 写 "0.75"，"2.000" 写 "2"，取整后为 0 的负数写 "0"）。不超过 4 位小数时不会出现指数形式，与数据模型 §2.1 的 ECMAScript 写法一致 [verify：用测试向量核对]。
- 角度先以网格编号（整数）算，度数＝编号 × 1.25 或 360/n，再按上一条取整。判据比较的是取整前的有理数（交叉相乘），类别不随显示位数变化。
- **D-034 的分层在 v1 里这样落**：决定身份和状态的量（`survived`、`locality`、`classes`、`trajectory`、各变体的 `survived`、`platonic`）和描述性的量（其余 measures）都逐位可复现。

### 6.5 更正、补测与套件升级【待 D-027】【新提议 AS16】

- **套件 bug**（D-027(4)）：修好，升补丁号或次版本号；受影响的证书靠重新运行找出（不靠人工挑），重新鉴定，签新证书；写 `certificate.corrected`（旧证书、新证书、原因码 `bug_fix`），旧证书标"已更正"。不再满足登记条件的按法规第 40 条撤回（数据模型 §4.3）。
- **补测**（自我修复从"未测"到测过，或第二阶段采纳了新类别）：签补充证书，同一事件、原因码 `supplement`，物种页写"已补测"，不写"已更正"。PRD F16 的"重新签发"按此实现。
- **升主版本**：不自动重鉴。旧证书继续有效，按旧套件解读；查重和浏览按证书的套件版本分开比较（[dedup v1](./dedup-v1.md)）。
- **新的规范版本**：条目不迁移（数据模型 §9 第 2 条）；套件在新规范开放登记前发布支持它的版本。

## 7. 算力、排队与优先级

### 7.1 粗算

直接求和时，一次运行的乘加次数 ≈ 步数 × N² × K，K ≈ πR² 是核内的格子数。下表以 R = 13、T = 10、D_0 ≈ 2R（GDD §14.5 示例的离散化）为例，基准运行为 1 份。全是粗算，以 M3 实测为准 [verify]：

| 运行 | R′、T′、N′ | 相对份数 |
|---|---|---|
| 基准运行 | 13、10、128 | 1 |
| R↓ | 6、10、128 | 约 0.2 |
| R↑ | 26、10、256 | 约 16 |
| T↓ | 13、5、128 | 0.5 |
| T↑ | 13、40、128 | 4 |
| 自我修复 8 × 100 个时间单位 | 13、10、128 | 0.4 |
| 分析（簇、对齐距离、角度搜索） | — | 约 0.1–0.5（要实测） |
| 复查（按条件） | 13、10、256 | 4 |

- 不含复查合计约 22 份。基准运行约 1.7 × 10^11 次乘加，按每核每秒 10^9–4 × 10^9 次（暂定）算，一次鉴定约 16–65 核分钟，与 GDD §14.3 的"几十个核分钟"、[团队预算 §3.2](../product/team-budget-funding.md) 的 m（20–100）同一量级。R↑ 约占 70%；S1 通过、启用 NTT 后这一项会明显变少 [verify：M1、M2]。
- **大 R 贵得多**：核的格子数和环面面积都随 R² 增长，成本大致随 R⁴ 增长。按同样的粗算，R ≈ 40（N = 256）的基准运行约 0.5–2 核小时；R↑ 判不了（§3.7），T↑ 仍是 4 份，整次鉴定约 3–12 核小时，远超计划 §6.4 的警戒线（100 核分钟）[verify]。M3 加测一个 R ≈ 40 的自有结构，结果和 D-028 的 R 上限一起看。
- 本文在存活加 4 组复跑之外另有自我修复和分析（约 2–4%），触发复查时再加约 18%。[测量报告](../phase0/measurements.md#measures) M3 已改为按本文的运行计划测，团队预算 §3.2 的 m 按实测更新。

### 7.2 队列与优先级【新提议 AS17】

| 道 | 内容 | 规则 |
|---|---|---|
| 1 更正 | D-027 的重新鉴定；阻塞登记的补测；证书键泄露后的重跑重签（系统架构 §7.4） | 最先 |

| 4 文献映射 | 有许可时的导入鉴定（§11） | 内部，空闲时跑 |
| 5 普查入库 | 进待描述库之前的鉴定（数据模型 §4.1） | 受普查月预算上限约束（团队预算 §3.2），可被抢占，不挤占第 2 道（PRD 砍单第 3 项的触发点） |

## 8. 失败模式与重试【新提议 AS18】

| 情况 | 处理 |
|---|---|
| 抢占式实例被回收、节点崩溃、超时 | 每个哈希链点（256 步）存一次状态，从最近的链点续跑，结果与一次跑完相同；最多重试 3 次（暂定），仍失败写 `engine_error`，告警，人工查 |
| 输入不合法、尺寸不对 | 不重试；原因码告诉玩家下一步（如尺寸不对要重新采集） |
| 同一输入两次结果不同 | 签发前不逐件双跑（太贵）；第 6 道随机抽 5%（暂定）已签证书，换一种平台重跑全部运行、比对证书主体。不一致就停止签发，必要时按法规第 49 条之一暂停登记，按规范 §9.3 定位，按 D-027 处理（PRD R04） |
| 套件 bug | §6.5 |
| 签名服务不可用 | 运行结果保留，排队等签名；不签就不写 `assay.certified` |
| 算力超预算 | §7.2 的停道顺序；PRD R14 |

## 9. 描述助手能从证书抄什么【新提议 AS19】

描述助手 v0 只用模板（PRD F33，PRD 第 13 节第 4 条的新提议；实现见 [AI 助手 v0](../data/ai-assistant-v0.md) 第 2 节），只起草测量段和近邻对照表，诊断和命名留给人（GDD §8.8、法规第 15 条）。**AI 声明**按 AI 助手 AI1–AI4【待 AI1、AI3、AI4】：描述者只点选单个数值原样插入的，是"原样引用机器结果"，不必声明（法规第 17 条第 2 款）；整段插入测量段（模板句）时，表单预填 `ai` 声明 `{part: behaviour, help: draft, tool: description-assistant/<模板版本>}`，描述者可以改（法规第 17 条第 1 款）；物种页把与模板输出逐字相同的句子标"机器测量"（"Machine measurement"）；第二阶段的自动化水位线不把模板句和原样引用的结果算作人的贡献。

**可以抄**（每个数字都带证书编号，原样照抄，不换单位、不再取整）：

- 存活：固定句"在 2000 个时间单位内存活（lenia-q16/1.0，N×N 环面）"，英文 "Survived 2000 time units (lenia-q16/1.0, N×N torus)"。
- 局域性、行为大类：用 §4.1 的中文名和枚举对应的英文名；`classes: []` 写"未归入行为大类"。
- 运动类别、`speed`（R/TU）、周期和 shape_period（步数和时间单位）、对称群、角速度。
- 自愈指数和分项；`"untested"` 照写"未测"，不估计。
- 离散化：测过的 R、T 和结果；柏拉图型用固定句"在测过的更细的 R、T 下都存活（操作性定义，不等于 Davis 2024 的判据）"，英文 "Survived at the finer R and T values tested (operational definition, not the criterion of Davis 2024)"；省略 `platonic` 时写"未能判定"和原因。
- 繁殖、辐射的事件数和率，连同 `observed_tu`。
- 与近邻的差异：只并列查重报告里公开近邻条目的证书与本证书都有的同名字段（[dedup v1](./dedup-v1.md)），只出表格、不写成句子，套件主版本不同的近邻不比较（AI 助手 §2.1、§2.2）。

**不能写**：证书和查重报告里没有的数字；浮点预览值（F10）；"永久""稳健""罕见""新颖"之类的评价（法规第 15 条第 3 款）；从测量推出原因；把柏拉图型说成"连续规则本身的性质"；把行为大类写成系统分类。

## 11. 文献导入的口径【待 D-040、D-042】【新提议 AS21】

法规第 42 条：`literature` 要求"量化到 lenia-q16 后仍能存活、行为没有明显改变（口径见 assay v1）"。只在有许可时适用；没有许可时只有 `literature_reference`，不跑。

- 参数落不到格点的直接 `literature_unreproduced`（D-024，交接规格第 6 节），不取整。落得到的，按文献映射方案（有许可时 P1-W1 完成，PRD 第 5 节）培养出成体快照，按本文完整鉴定，走第 4 道。
- 判为 `literature` 要同时满足：鉴定通过；局域性为个体（论文描述为扩张的除外）；同一快照的 float64 运行（测量报告 §1 的对比方法，非规范，只在一个固定的原生平台上跑，同规范附录测试协议第 10 条）每帧按 rne 量化成 16 位后交给本文的分析程序，得到的类别集合与整数版相同，速度、周期、质量落在测量报告 §1 冻结的容差内；再由人只看原文的图和文字，核对没有明显矛盾（法规第 45 条第 4 款）。
- 任何一项不满足 → `literature_unreproduced`，条目写明哪一项（法规第 42 条）。不为通过而调参（法规第 44 条）。G-文献可见 之前，结果只在私密暂存区（数据模型 N18），不公开（D-040 第 4 条）。
