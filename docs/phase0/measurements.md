## 1. 行为一致：对比方法与容差（G2）

**对比方法**：整数版和 float64 版从**同一个**量化后的成体快照出发（float64 版把整数状态除以 65535），用同一组规则参数、同一个环面，各跑 2000 个时间单位。float64 版直接用 GDD 附录 A 的连续公式计算核权重和生长函数，不做量化。

**噪声基线**（W2，容差冻结之前做）：float64 对 float64。同一个快照，一份不动，另一份在每个非零格子上随机加或减 1 个最低有效位（即 ±1/65535，种子固定，暂定），两份各跑 2000 个时间单位，按下表的每一项测出差异，作为这一项的自然波动。每个基准物种都做一次。

| 项目 | 容差（全部暂定；不小于噪声基线的 2 倍） |
|---|---|
| 存活 | 结论相同：都存活且质量有界，或者都不存活（GDD §8.3 的定义） |
| 行为大类 | 相同（GDD §8.3：固着体、振荡体、移动体、旋转体等） |
| 速度 | 按 R 归一化的平均速度（R 每时间单位，同 [assay v1](../tech/assay-v1.md) §3.3；取后 1000 个时间单位）相差 ≤ 5% |
| 运动方向 | 相差 ≤ 5° |
| 角速度（旋转体） | 相差 ≤ 5% |
| 周期 | 步数相同，或相差 ±1 步；准周期或无周期的物种比较主频率，相差 ≤ 5% |
| 质量 | 时间平均的总质量相差 ≤ 2% |
| 形态 | 对 float64 版最后 100 个时间单位的每一帧，在整数版最后 100 个时间单位里找出交并比最高的一帧（掩膜按阈值 0.1 二值化，按质心对齐，在旋转和相位上都取最佳匹配）。这些最佳交并比的中位数 ≥ 0.9。逐帧直接比较不行：跑完 2000 个时间单位后，振荡体和移动体的相位必然已经错开 |

- **冻结**：W2 末冻结上表（计划 §6.3）。冻结后只能收紧；要放宽，必须在看到 W3 结果之前写进决策日志并说明原因。
- **非柏拉图型物种**可以不满足以上任何一项，但对比表要写明哪几项不满足、差多少。G1 对它们同样适用。
- **柏拉图型**：Davis（2024）没有归为非柏拉图型的，一律按柏拉图型判定。
- **这些容差来自文献种**：噪声基线和冻结容差都是在 D-045 的基准物种上测的，基准物种就是 Chan（2019）的文献种。所以逐物种的噪声和对比结果不公开（文首的保密规则，D-040 第 4 条）；第一阶段从它们推出、要公开的阈值（[assay v1](../tech/assay-v1.md) §5 的阈值表、[种子悬赏](../community/seed-bounties.md) §3.5）只能用不写物种名的汇总，做不到时改在自有结构上重测【待 D-040】。

## 2. 测量的定义与条件（M1–M7）

只要求测量并记录，没有通过线。警戒线和用途见计划 §6.4。

| 编号 | 测量 | 条件 | 产出 |
|---|---|---|---|
| M1 | NTT 吞吐 | P1，单核和全部核心；256² 和 512²；R = 13 和 R 约 50 | 步/秒 |
| M2 | 直接求和与 NTT 的交叉点 | P1；R 从 5 到 60（暂定）扫描；256² 和 512² | 从哪个 R 开始 NTT 更快 |
| M3 | 单次鉴定的核分钟数 | 128² 和 256² 窗口；按 assay v1 §2.3 的运行计划：基准运行 2000 个时间单位，4 组离散化变体（T = 10 时 T↑ 即 T = 40，D-033），8 次自我修复，触发时的复查另记。另测一个 R ≈ 40 的自有结构（256²；R↑ 判不了，只有 3 组变体，assay v1 §3.7、§7.1），不用文献种 | 核分钟；按 GDD §6 的"十分钟以内"推算需要的并行度；更新[团队预算](../product/team-budget-funding.md) §3.2 的 m。R ≈ 40 一项单列，不计入 m，不按警戒线判，和 D-028 的 R 上限一起看 |
| M4 | 预览步速 | Chrome，WebGPU 浮点，256²，中端笔记本的集成显卡（型号写进报告）；Firefox、Safari 能跑就一起测 | 步/秒 |
| M5 | 浏览器里精确复现的速度 | P4–P6，WASM 整数版，Orbium，2000 个时间单位 | 秒 |
| M6 | 浮点与整数的分岔步数 | float64 对整数，float32（GPU 预览）对整数；分别从成体和随机汤出发；浮点状态按 `q16-rne/1` 量化（[采集交接](../tech/collection-handoff.md) CH5） | 两边状态之差（L1，按总质量归一化）首次超过 1%（暂定）的步数 |
| M7 | 幻影率 | 试玩中采集的全部候选：把采集时的状态按 `q16-rne/1` 量化到 16 位，裁切和尺寸按采集交接 CH4，在整数版里跑 2000 个时间单位；预览的核两种都试（CH9）。这样第 0 阶段和 alpha（CH19）的幻影率才能比。用现成程序试玩时，按它的导出格式存下候选再复跑；导不出来的写明 | 活不下来的比例。警戒线 > 20%（暂定），即 D-029 的幻影率阈值（提议） |
